### Variantes com parâmetro

O mesmo destino muda de acordo com a página. Não são links diferentes para o
Google — são o mesmo endereço com contexto — mas é o que o visitante recebe.

**WhatsApp** (`wa.me/5527998713993?text=…`), uma mensagem por contexto:

| página | mensagem que já vai escrita |
|---|---|
| `/unidades/` | "…gostaria de ajuda para escolher a unidade." |
| cada unidade | "…pela página da unidade <nome>, e gostaria de informações." |
| `/servicos/` | "…gostaria de informações sobre os serviços." |
| `/servicos/corte-masculino/` | "…sobre o corte masculino." |
| `/servicos/barboterapia/` | "…sobre a barboterapia." |
| `/visagismo/` | "…sobre o visagismo." |
| `/dia-do-noivo/` | "…informações sobre o Dia do Noivo." |
| `/o-clube/` | "…informações sobre o Clube." |
| `/corporativo/` | "…informações sobre os planos corporativos." |
| `/trabalhe-conosco/` | "…enviar meu interesse profissional." |
| demais | "Olá! Vim pelo seu site e quero agendar um corte como visitante" |

**Google Maps** (`google.com/maps/dir/?api=1&destination=…`), uma rota por unidade:

| unidade | destino |
|---|---|
| Cidade Continental | Avenida Terceiro Mundo, Cidade Continental — Setor Ásia, Serra - ES, 29163-603 |
| Novo Horizonte — Av. Brasil | Avenida Brasil, Novo Horizonte, Serra - ES, 29163-331 |
| Novo Horizonte — Av. Industrial | Avenida Industrial, 830 — Loja 3, Novo Horizonte, Serra - ES, 29163-357 |

O mapa embutido na página de cada unidade usa `maps.google.com/maps?q=…&output=embed`
com o mesmo endereço.

### O que ainda não existe

- **Perfil da Empresa no Google** de cada unidade: enquanto o cliente não
  mandar o link, "Como chegar" abre a rota pelo endereço, não pelo perfil.
- **Agenda por unidade**: os três botões "Agendar nesta unidade" levam ao mesmo
  endereço geral do Cashbarber, porque `bookingUrl` das três é o mesmo.
- **Instagram e Facebook**: o site não publica nenhum perfil social.
